# PWA Icons

This directory should contain the following icon sizes for the PWA:

- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png (required for PWA)
- icon-384x384.png
- icon-512x512.png (required for PWA)

## Requirements

- All icons should be PNG format
- Icons should be square
- The 192x192 and 512x512 sizes are mandatory for PWA installation
- Icons should have a transparent or white background to match the theme

## Generating Icons

You can use tools like:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator
- Or any image editing tool to resize your base icon

Make sure to create icons that work well as "maskable" icons (with safe zone padding) for Android adaptive icons.
