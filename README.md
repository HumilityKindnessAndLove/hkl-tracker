# HKL Interaction Tracking App

## Quick start
1. Install dependencies:

```bash
npm install
```

2. Copy `.env.example` to `.env.local` in the project root and fill in the values.

Windows:
```cmd
copy .env.example .env.local
```

Unix (macOS, Linux):
```bash
cp .env.example .env.local
```



3. Run the dev server:

```bash
npm run dev
```

4. Open http://localhost:3000 in your browser.

## VS Code recommendations
- Install the recommended workspace extensions (look for the prompt when opening the project) or explicitly install:
  - Biome
  - Tailwind CSS IntelliSense
